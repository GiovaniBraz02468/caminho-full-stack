# caminho-full-stack
Este repositório reúne projetos desenvolvidos com o objetivo de fortalecer minhas habilidades como desenvolvedor full-stack, utilizando principalmente React (Vite) no frontend e C# ASP.NET no backend.

Os projetos aqui presentes foram criados para praticar conceitos importantes de desenvolvimento web moderno, explorando integração entre frontend e backend, consumo de APIs e boas práticas de arquitetura.
